Brain World

A creature with eyes, ears, two legs, an arm and a pen. Nothing tells it what to do. It only gets a dopamine signal when something goes better than it expected, and from that alone it learns five skills in a row: walk, grasp, listen, read and write. Leave it running and watch it get there.

    How its brain works

    Each step its senses are a 15-ray colour retina, a 5×5 fovea that can resolve letters (with a short, fading memory of the last one), three cochlea bands (one per tone, which you hear too) and the position of its legs. A fixed random layer of 1,000 neurons mixes them, and sound scales each neuron's visual response up or down, the way attention scales responses in visual cortex. Each skill switches off a fixed random half of that layer, so skills mostly use different neurons (a hypothesis about how prefrontal cortex keeps tasks apart). On top sits an actor (which action next) and a critic (how good is this moment). Dopamine is the critic's surprise. Synapses that were recently active keep an eligibility trace, and they change only when that trace meets dopamine. There is no backpropagation and no programmed behaviour.

    Settled science: dopamine signals reward prediction error, and plasticity needs a trace plus a neuromodulator. Hypothesis: that this simple stack is enough for a real brain's versions of these skills. Once walking is learned the gait becomes automatic, as practised skills move to habit circuits, so the later stages choose steps, not leg lifts. One network learning skill after skill overwrites the old ones (catastrophic forgetting), so about a third of the episodes rehearse an earlier skill, as the hippocampus replays old experience between new learning. Not every new brain gets there: some stall on listening or reading, as any learner can. Read more in build-a-brain-like-learner and learning-and-plasticity.

    A brain learning from scratch

    The purple creature starts knowing nothing: not how to walk, not what food is.

    Its only teacher is dopamine, a signal that fires when things go better than it expected. From that alone it learns to walk, grasp food, follow a tone, read a letter and write one.
