# research/

| Path | What |
|---|---|
| [implementation-status.md](implementation-status.md) | Which open and closed issues are actually implemented, tested and recorded on `main`, with file links (#103). Lists closed issues whose code was never pushed (#128). |
| [papers.md](papers.md) | Every reference cited by the topic files: citation, which topics cite it, DOI/link, open-access status, PDF link. Generated, and refreshed weekly by the `Paper catalog` workflow, which opens a PR when it changes. |
| [fetch_papers.py](fetch_papers.py) | Builds `papers.md` offline from the topics and `papers.json` (the cache of OpenAlex lookups); `--check` fails when it is out of date (CI runs it); `--enrich` looks new references up online; `--pdf` downloads open-access PDFs. Stdlib only. |
| [learning-algorithm-hypotheses.md](learning-algorithm-hypotheses.md) | Research thread: 170 ranked, testable hypotheses on the brain's unknown learning algorithm (abstraction, language, reasoning), with Next up and a results log. Start here to resume. |
| [hypotheses-explained/](hypotheses-explained/README.md) | Every one of the 170 hypotheses in simple language, with a step-by-step brain workflow (if true) and a test workflow. One file per section A-K. |
| [learning-algorithm-sources.md](learning-algorithm-sources.md) | The 185 papers cited by the hypotheses: verdict, official link, open-access PDF. Generated by `verify_sources.py` from `learning-algorithm-sources.tsv`. |
| [learning-algorithm-notes/](learning-algorithm-notes/README.md) | Per-paper notes for those sources: question, method, experiments, key results, caveats, and whether each paper supports its hypothesis row. |
| [verify_sources.py](verify_sources.py) | Checks each source in the TSV (Crossref, then Semantic Scholar), downloads open-access PDFs to `pdfs/learning-algorithm/` and links the citations in the hypotheses file. Stdlib only. |
| [replay_selection.py](replay_selection.py) | Experiment for #84: which replay selection rule (random, recent, high error, least replayed) protects old tasks best per replayed sample, with and without SHY-style downscaling. numpy, about a minute. Result in `function/sleep-and-memory-consolidation.md`. |
| [credit_assignment.py](credit_assignment.py) | Experiment for #92 (H001-H003): do predictive coding updates match backprop's gradients, and do feedback alignment and direct feedback alignment train hidden layers? numpy plus sklearn's bundled digits (`pip install ".[research]"`), about 10 seconds. Result in `learning/brain-inspired-learning-algorithms.md`. |
| [dendritic_neurons.py](dendritic_neurons.py) | Experiment for #85: point neurons (one or two dense hidden layers) vs two-layer dendritic neurons at equal parameters and multiply-adds, on parity, a feature-conjunction task and 8x8 digits, trained by backprop and by feedback alignment. numpy plus sklearn's digits, a few minutes (learning-rate tuning included). Result in `anatomy/dendritic-computation.md`. |
| [brainscore_saturation.py](brainscore_saturation.py) | Analysis for #88: has the ImageNet-accuracy to Brain-Score link saturated? Line vs hinge fits per score (average, neural, behaviour, V1-IT), rank tests above 70% top-1, and an exploratory pretraining-data control. numpy, a few seconds. `--fetch` saves a new dated leaderboard snapshot to `data/`. Result in `function/sensory-systems-and-vision.md`. |
| [h101_transfer.mjs](h101_transfer.mjs) | Experiment for H101: in Brain World's listen task, train with red, green and blue objects, then time how fast each arm passes with yellow, cyan and magenta. Arms: the local rule, the local rule plus sleep replay, and backprop into the same network; for H103 also each of the first and third with a colour-blind where-pathway prior. Node, about 40 minutes for 5 seeds. Result in `learning/brain-inspired-learning-algorithms.md`. |
| [result_schema.py](result_schema.py) | The shared result file for learning experiments (#104), `brain-result/1`: commit, command, environment, full config, budgets, metric directions, and one row per arm x seed with status (`ok`, `failed`, `timeout`, `error`), reason, seconds and scores. Failed and crashed runs stay in the denominators. Validates a file and prints per-arm means with bootstrap 95% intervals and paired sign-flip p values against the baseline arm. Runs that carry a `split` (a task) are summarised per split, never pooled. `make_result()` builds one from Python; `game/world/result.mjs` from Node. Written with `--out` by `replay_selection.py`, `credit_assignment.py` (H002/H003), `dendritic_neurons.py`, `h101_transfer.mjs` and `game/world/` `sweep.mjs`, `reversal.mjs`, `transfer.mjs`; not by `brainscore_saturation.py`, a regression on one leaderboard snapshot with no arms or seeds. Stdlib only; `test_result_schema.py` checks it against `results/fixtures/sweep.log`. |
| `data/` | Small dated snapshots of public data the analyses read (Brain-Score vision leaderboard: model, ImageNet top-1, average, neural, behaviour and per-region scores). |
| `pdfs/` | Downloaded open-access PDFs. Git-ignored (publisher copyright); run the script to fetch them. |

```
python research/fetch_papers.py            # rebuild papers.md offline (after editing references)
python research/fetch_papers.py --check    # is papers.md current? (offline, CI)
python research/fetch_papers.py --enrich   # online: look up references new since the last run
python research/fetch_papers.py --enrich --pdf   # ...and download open-access PDFs
python research/verify_sources.py          # re-check the hypotheses' sources + fetch PDFs
python research/replay_selection.py        # replay rule experiment (#84); --quick for a smoke run
python research/credit_assignment.py       # PC vs backprop, FA, DFA (#92); --quick for a smoke run
python research/dendritic_neurons.py       # point vs dendritic neurons (#85); --quick for a smoke run
python research/brainscore_saturation.py   # Brain-Score saturation re-check (#88); --fetch for a new snapshot
python research/result_schema.py run.json  # validate a result file and summarise it per arm (#104)
node research/h101_transfer.mjs            # local rule (+ replay) vs backprop transfer (H101), and prior arms (H103); --quick for a smoke run
```

Re-run after adding references to a topic. It resolves each reference through
OpenAlex (DOI, arXiv id, or exact title) and tries the open-access PDF URLs
OpenAlex and Semantic Scholar report. Publishers that answer scripts with a bot
check (eLife, bioRxiv, PMC, J Neurosci) stay as `oa` links: open them in a
browser. Closed-access papers are listed with their DOI only.

The per-paper findings, grouped by theme, are in
[guides/key-papers.md](../guides/key-papers.md).

## Audit (2026-10-11) in brief
An external audit of the repo recommended, before adding more topics: CI, a
license, `pyproject.toml`, community files, headless level-winnability tests,
read-only CI permissions, unique topic names in `build_index.py`, atomic save
files, independent review of the `draft` topics, and a per-model scorecard
against published data. All of these have landed except two: splitting
`game/levels.py` into a pure level engine plus Tk UI, and the topic review
(issue #21). Its evaluation advice now lives in
[simulation/evaluating-brain-models.md](../simulation/evaluating-brain-models.md).
The full report is in git history (`git show 033e79a:research/deep-research-report.md`).
